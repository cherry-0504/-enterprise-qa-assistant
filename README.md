# 企业员工智能问答助手

## 一、项目简介

本项目是一个基于 Dify 平台搭建的企业员工智能问答助手原型，使用 RAG（检索增强生成）技术，将企业制度文档与大语言模型结合，为员工提供日常制度查询服务。

## 二、项目功能

- 企业考勤制度查询
- 员工请假流程查询
- 加班规定查询
- 报销流程查询
- 基于知识库内容生成回答
- 知识库没有相关信息时，提示用户补充信息或说明暂未找到依据

## 三、技术与工具

- Dify：低代码 AI 应用开发平台
- LLM：大语言模型
- RAG：检索增强生成
- 向量检索：从知识库中检索相关文本
- Prompt Engineering：通过提示词约束回答行为

## 四、系统实现流程

用户提问 → 知识库检索 → 将检索结果传递给大语言模型 → 生成回答 → 返回给用户

## 五、知识库说明

项目使用自行编写的模拟企业考勤与请假制度文档作为测试数据，内容仅用于学习和演示，不代表任何真实企业的正式制度。
